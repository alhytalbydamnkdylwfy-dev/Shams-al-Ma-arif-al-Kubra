# AZAZIL

موقع عربي بسيط يعرض كتاب **شمس المعارف الكبرى** فقط.

## إضافة النسخة المصوّرة
1. احصل على نسخة PDF موثوقة ومسموح بإعادة نشرها.
2. ضع ملف PDF بجانب `index.html`.
3. أعد تسمية الملف إلى `book.pdf`.
4. افتح `index.html` محلياً للتجربة، أو ارفع الملفات إلى مستودع GitHub.

## النشر عبر GitHub Pages
1. أنشئ مستودعاً جديداً باسم `AZAZIL`.
2. ارفع `index.html` و`style.css` و`script.js` و`README.md` و`book.pdf`.
3. من Settings ثم Pages، اختر النشر من فرع `main` ومجلد `/ (root)`.
4. احفظ الإعدادات وانتظر إنشاء رابط الموقع.

## ملاحظة مهمة
هذا القالب لا يتضمن نسخة من الكتاب. يجب إضافة ملف PDF بنفسك بعد التحقق من مصدره وحقوق إعادة نشره، مع ذكر بيانات الطبعة أو المخطوطة بوضوح.
